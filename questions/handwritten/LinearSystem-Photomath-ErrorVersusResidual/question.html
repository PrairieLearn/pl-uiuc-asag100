Correct solution for reference

The correct solution below is provided only for reference.

  1. \[ \begin{aligned} {{params.a}}x_1+{{params.b}}x_2&={{params.rhs1}},\\ {{params.c}}x_1+{{params.d}}x_2&={{params.rhs2}}. \end{aligned} \] \[ \Delta=({{params.a}})({{params.d}})-({{params.b}})({{params.c}}) ={{params.determinant}}\ne0. \] \[ \begin{aligned} x_1&=\frac{({{params.rhs1}})({{params.d}})-({{params.b}})({{params.rhs2}})} { {{params.determinant}} }={{params.solution_x1}},\\[6pt] x_2&=\frac{({{params.a}})({{params.rhs2}})-({{params.rhs1}})({{params.c}})} { {{params.determinant}} }={{params.solution_x2}}. \end{aligned} \] \[ \mathbf{x}={{params.solution_vector}}. \]
  2. \[ \mathbf{A}\hat{\mathbf{x}} ={{params.arep}}{{params.estrep}} =\begin{pmatrix} ({{params.a}})({{params.estimate_x1}})+({{params.b}})({{params.estimate_x2}})\\ ({{params.c}})({{params.estimate_x1}})+({{params.d}})({{params.estimate_x2}}) \end{pmatrix} ={{params.product_vector}}. \] \[ \mathbf{r}=\mathbf{b}-\mathbf{A}\hat{\mathbf{x}} ={{params.brep}}-{{params.product_vector}}={{params.resrep}}. \]
  3. \[ \mathbf{e}=\mathbf{x}-\hat{\mathbf{x}} ={{params.solution_vector}}-{{params.estrep}}={{params.error_vector}}. \]

  4. Use the residual because it can be computed from $\mathbf{A}$, $\mathbf{b}$, and $\hat{\mathbf{x}}$. In general, the error cannot be computed since the true solution is not known.
