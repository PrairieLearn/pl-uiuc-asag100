Correct solution for reference

The correct solution below is provided only for reference.

  2. \[ (+\uparrow)\qquad W=wa=({{params.w}})({{params.a}})={{params.R}}\,\mathrm{kN} \] \[ \sum F_y=0:\quad R_y-W=0, \qquad |R_y|={{params.R}}\,\mathrm{kN}. \]
  3. \[ (+\circlearrowleft)\qquad \bar{x}={{params.load_centroid_symbol}}={{params.load_centroid_latex}}\,\mathrm{m} \] \[ \sum M_{x=0}=0:\quad M_A-W\bar{x}{{params.moment_balance_sign}}M_o=0 \] \[ \begin{aligned} M_A&=W\bar{x}{{params.reaction_moment_sign}}M_o\\ &=({{params.R}})({{params.load_centroid_latex}}) {{params.reaction_moment_sign}}({{params.mo}})\\ &={{params.moment_magnitude_latex}}\,\mathrm{kN\,m}, \qquad |M_A|={{params.moment_magnitude_latex}}\,\mathrm{kN\,m}. \end{aligned} \]
